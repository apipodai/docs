## Usage notes

- **Source video**: pass exactly one MP4/MOV video (3-15.5 seconds) in `video_urls`, plus up to 4 optional reference images. Output duration and aspect ratio follow the source video, so `duration` and `aspect_ratio` are not accepted. Set `keep_original_sound` to `true` to keep the original audio.
- **Referencing inputs**: images are numbered `image_1`..`image_N` in order and the video is `video_1`. Use `@image_1` / `@video_1` in the prompt to point at a specific input.
- **Not supported**: `negative_prompt` (write exclusions into the prompt), `audio_urls`, and `video_url` (use `video_urls`).

## Billing

Billed per second of the source video duration (rounded up to whole seconds), using the enhanced tier for 720p/1080p (or the 4K tier). The per-second rate depends on the tier: 720p basic, 720p enhanced, 1080p basic, 1080p enhanced, or 4K. The enhanced tier applies when native audio is enabled or any video input is provided. Current prices are shown on the [model page](https://www.apipod.ai/models).

## Task flow

The create call returns `data.task_id`. Poll [Query video task](/query-video-task) until `status` is `completed` (outputs in `data.result`) or `failed`, or pass `callback_url` to be notified when the task reaches a terminal state.
