## Usage notes

- **First frame**: pass exactly one image in `image_urls`; last frames are not supported. The output aspect ratio follows the image.
- **Multi-shot**: describe up to 6 shots in `multi_prompt` (`{prompt, duration}`, up to 512 characters each). Shot durations must add up to exactly `duration` (3-15 seconds). `multi_shot` is not accepted.
- **Audio**: native audio is always generated; `generate_audio: false` is rejected.
- **Not supported**: `negative_prompt` (write exclusions into the prompt), `audio_urls`, and `video_url` (use `video_urls`).

## Billing

Billed per second of output video. The per-second rate depends on the resolution (720p or 1080p); native audio is always included. Current prices are shown on the [model page](https://www.apipod.ai/models).

## Task flow

The create call returns `data.task_id`. Poll [Query video task](/query-video-task) until `status` is `completed` (outputs in `data.result`) or `failed`, or pass `callback_url` to be notified when the task reaches a terminal state.
