## APIPod support

In APIPod, the public model ID is gemini-omni-r2v. It supports image-to-video, accepts text and image inputs, and returns results through asynchronous video tasks.

<Warning title="Conditional validation">Provide between one and five reference images.</Warning>

<Card title="Query task status" icon="search" href="/query-video-task">Use the task_id returned by the create endpoint to retrieve progress and results.</Card>
