## APIPod support

In APIPod, the public model ID is minimax-h3-r2v. It supports image-to-video and video-to-video, accepts text, image, audio and video inputs, and returns results through asynchronous video tasks.

<Warning title="Conditional validation">Provide at least one reference asset. The per-media limits are defined by the API schema.</Warning>

<Card title="Query task status" icon="search" href="/query-video-task">Use the task_id returned by the create endpoint to retrieve progress and results.</Card>
