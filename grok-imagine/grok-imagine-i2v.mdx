## APIPod support

In APIPod, the public model ID is grok-imagine-i2v. It supports image-to-video, accepts text and image inputs, and returns results through asynchronous video tasks.

<Warning title="Conditional validation">Provide either `image_url`/`image_urls` or `task_id`, but not both. `index` is valid only with `task_id`.</Warning>

<Card title="Query task status" icon="search" href="/query-video-task">Use the task_id returned by the create endpoint to retrieve progress and results.</Card>
