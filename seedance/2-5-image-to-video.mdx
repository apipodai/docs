The Seedance family emphasizes prompt following, coherent motion, multi-shot storytelling, and synchronized audio. This is a full-capability variant: media URLs are submitted to the asset review service before the task is submitted, so plain public URLs always work in requests."

<Note title="Aspect ratio follows the first frame">The output aspect ratio automatically keeps consistent with the first frame image. The `aspect_ratio` field is not part of the contract - any passed value is silently ignored and `adaptive` is always sent.</Note>
