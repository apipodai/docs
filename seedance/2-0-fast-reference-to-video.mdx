## APIPod support

In APIPod, the public model ID is seedance-2.0-fast-r2v. It supports text-to-video, image-to-video and video-to-video, accepts text, image, audio and video inputs, and returns results through asynchronous video tasks.

<Warning title="Conditional validation">Provide at least one reference asset. The per-media limits are defined by the API schema.</Warning>
