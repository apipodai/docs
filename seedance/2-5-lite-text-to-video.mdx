## Key Parameters and Limits

Seedance 2.5 Lite Text to Video shares the full 2.5 contract with the discount routes — 4–30 second clips with native audio-video joint generation — and differs only in billing tier and resolution: special-offer billing, 720p-only output.

- **Text prompt**: For Chinese, keep it under 500 characters; for English, under 1,000 words.
- **Duration**: 4–30 seconds per clip (default 4s).
- **Resolution**: 720p only — 480p, 1080p, 2K and 4K are not supported on this route.
- **Aspect ratio**: `adaptive` (default), `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`.
- **Native audio**: generated with the picture and on by default (`generate_audio=true`); disable per request if not needed.

<Note>
Special-offer billing applies and only successful tasks are charged — see the pricing page for live rates. This is a full-capability route: media URLs are submitted to the asset review service before the task is submitted by default (real_person=true); set real_person=false only when the materials are confirmed face-free to pass media URLs through as-is, so plain public URLs always work in requests.
</Note>
