## Real-person review (real_person)

When a request carries reference materials, the boolean `real_person` field declares whether the materials contain real people (human faces):

- `real_person: true`: materials are submitted to the asset review service first, and the task is created with `assetId://{assetId}` references; the task waits during review and fails if review rejects the materials.
- `real_person: false` (default): review is skipped and material URLs are passed through to task creation as-is.

Set it to `true` only when the materials actually contain real people to avoid unnecessary review latency; keep the default for landscapes, products, and other face-free materials.

## Asset library references

Besides publicly accessible URLs, the `image_url` / `image_urls`, `video_urls`, and `audio_url` / `audio_urls` fields also accept asset library references in the form `assetId://{assetId}`. Asset IDs are shared across the platform: any account may reference a known `assetId`, regardless of who submitted it — the same sharing semantics as a public URL. Only `ACTIVE` assets pass validation. Submit and track assets via [asset upload](/seedance/asset-upload) and [asset detail](/seedance/asset-detail).
