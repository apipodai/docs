## APIPod 支持

在 APIPod 中，公开模型 ID 为 minimax-h3-r2v，支持图生视频、视频到视频；接受文本、图片、音频、视频输入，并通过异步视频任务返回结果。

<Warning title="条件校验">必须至少提供一种参考素材；图片、视频和音频的数量上限以 API 参数定义为准。</Warning>
