## 列出已启用 LLM 模型

`GET /v1/models` 是公开端点，以 OpenAI 或 Responses API 格式列出已启用的 LLM 模型。它不是完整的图片和视频模型目录。

```bash
curl https://api.apipod.ai/v1/models
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model-id",
      "object": "model",
      "created": 1786358400,
      "owned_by": "provider",
      "classifications": ["text"]
    }
  ]
}
```

<Note>
  上述响应只展示结构。模型可用性会变化，请通过实时端点或模型目录发现 ID，不要硬编码示例条目。
</Note>

## 选择媒体模型

1. 根据所需输入与输出选择图片或视频模型系列。
2. 打开精确模型页面，核对必需媒体输入、时长、宽高比、分辨率和输出限制。
3. 使用页面提供的 JSON 请求体，以及 cURL、Python、Go、Rust 或 JavaScript 示例。
4. 保持公开 `model` 值不变，不要替换为提供商上游模型 ID。
