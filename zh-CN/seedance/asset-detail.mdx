路径参数支持纯 ID 或 `assetId://{assetId}` 引用形式。查询时系统会同步上游素材状态，因此轮询本接口可以拿到最新处理状态。只有 `ACTIVE` 状态的素材可以提交视频生成任务。

素材详情查询仅限本人提交的素材；但生成请求中的引用不受此限制——任何账号都可以通过 `assetId://{assetId}` 引用已知的素材 ID，与公开 URL 的共享语义一致。`assetId://` 引用仅 Seedance 2.0/2.5 系列生成接口支持。

## 素材状态说明

| `status` | 含义 | 建议动作 |
| --- | --- | --- |
| `NONE` | 素材记录已创建，但尚未开始处理。 | 稍后再次查询，当前不可提交任务。 |
| `UPLOADING` | 素材正在上传。 | 稍后再次查询，当前不可提交任务。 |
| `PROCESSING` | 素材正在处理中。 | 稍后再次查询，当前不可提交任务。 |
| `ACTIVE` | 素材已处理完成且可用。 | 只有此状态可以提交视频生成任务。 |
| `FAILED` | 素材处理失败。 | 查看 `errorMessage`，处理后重新提交素材。 |
| `EXPIRED` | 素材已过期。 | 继续查询素材详情并等待重新处理为 `ACTIVE`，必要时重新提交素材。 |
| `DELETED` | 素材已被删除或已失效。 | 重新提交素材并等待状态变为 `ACTIVE`。 |
