## Usage notes

- **Prompt only**: send `prompt` (required, up to 8,000 characters) with optional `duration` (3-30 seconds), `resolution` (`720p` or `1080p`) and `aspect_ratio` (`16:9`, `9:16`, `1:1` or `21:9`). Images and reference materials are not accepted; use [Kling 4.0 Image to Video](/kling-4.0/kling-4.0-i2v) or [Kling 4.0 Reference to Video](/kling-4.0/kling-4.0-r2v).
- **Audio**: every clip includes native audio generated together with the picture, so there is no `generate_audio` parameter — sending it is rejected.
- **Not supported**: `negative_prompt` (write exclusions into the prompt), `multi_shot` / `multi_prompt`, `mode`, and 4K output.

## Billing

Billed per second of output video. The per-second rate depends on the resolution (720p or 1080p). Current prices are shown on the [model page](https://www.apipod.ai/models).

## Task flow

The create call returns `data.task_id`. Poll [Query video task](/query-video-task) until `status` is `completed` (outputs in `data.result`) or `failed`, or pass `callback_url` to be notified when the task reaches a terminal state.
