## Usage notes

- **Frames**: `image_urls[0]` is the required first frame and an optional `image_urls[1]` is the last frame. Put middle frames in `keyframe_urls` in chronological order (up to 8). The output aspect ratio follows the first frame, so `aspect_ratio` is not accepted.
- **Frame limit**: the total number of frames (first + keyframes + last) is capped by `duration`: 3s → 4, 4s → 5, 5s → 6, 6s → 7, 7s → 8, 8s → 9, 9s or longer → 10. Exceeding the cap returns a 400 error before a task is created.
- **Mentioning frames**: use `@first_frame`, `@keyframe_1`..`@keyframe_N` and `@last_frame` in the prompt to describe what happens at each frame. Only frames you provided can be mentioned.
- **Audio**: every clip includes native audio, so there is no `generate_audio` parameter — sending it is rejected.
- **Not supported**: `negative_prompt`, `multi_shot` / `multi_prompt`, reference videos, `kling_elements`, `voices`, and 4K output.

## Billing

Billed per second of output video. The per-second rate depends on the resolution (720p or 1080p) and does not change with the number of frames. Current prices are shown on the [model page](https://www.apipod.ai/models).

## Task flow

The create call returns `data.task_id`. Poll [Query video task](/query-video-task) until `status` is `completed` (outputs in `data.result`) or `failed`, or pass `callback_url` to be notified when the task reaches a terminal state.
