openapi: "api-reference/openapi/genjutsu--genjutsu-light-1-0-object-swap.yaml POST /v1/videos/generations"
---

<Note>
Pass exactly 1 public HTTPS MP4 video in `video_urls` (`4–30s`) and `1–10` public HTTPS replacement images in `image_urls`. Supports `720p` (default) and `1080p` only—use `genjutsu-1.0-object-swap` if you need `480p`. Use `@video_1` and `@image_1` in the optional `prompt`; output duration and aspect ratio follow the source video.
</Note>
