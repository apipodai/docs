Every generation request includes a public APIPod model ID in the `model` field. Use the ID exactly as documented; provider routing is handled by APIPod and is not part of the public request contract.

## List enabled LLM models

`GET /v1/models` is public and returns enabled LLM models that expose the OpenAI or Responses API format. It is not the complete image and video catalog.

```bash
curl https://api.apipod.ai/v1/models
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model-id",
      "object": "model",
      "created": 1786358400,
      "owned_by": "provider",
      "classifications": ["text"]
    }
  ]
}
```

<Note>
  The response above illustrates the shape only. Model availability changes over time, so discover live IDs from the endpoint or the model catalog instead of hardcoding this example entry.
</Note>

## Choose a media model

1. Select an image or video family based on the input and output you need.
2. Open the exact model page and verify required media inputs, duration, aspect ratio, resolution, and output limits.
3. Use that page's JSON request body and one of its cURL, Python, Go, Rust, or JavaScript examples.
4. Keep the public `model` value unchanged; do not substitute a provider's upstream model identifier.
